Wayfinder Router {{ .Chart.AppVersion }} has been installed as {{ include "wayfinder-router.fullname" . }}.

The gateway is bound to the cluster-internal Service on port {{ .Values.service.port }}.
It is configured for the authenticated data-plane surface. Before sending traffic,
provide a complete gateway TOML through config.existingSecret or config.existingConfigMap
with at least one virtual key and one model destination.

{{- if .Values.redis.enabled }}
This release includes a single-replica Redis instance for shared policy state.
It uses a persistent AOF claim by default. Disable persistence only for a
disposable evaluation.
{{- else }}
Redis is disabled. The required config.existingSecret must contain the external
shared-state URL; use certificate-validated rediss:// outside a trusted network.
{{- end }}

{{- if .Values.ingress.enabled }}
Ingress is enabled. TLS and controller-specific HTTPS-only annotations are
required outside the explicit local-development escape hatch.
{{- else }}
Ingress is disabled. Use port-forwarding for a local smoke test:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "wayfinder-router.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
{{- end }}

Credentials are read from the referenced Secret as environment variables. Do not
put API keys or bearer tokens in a ConfigMap, route receipt, or chart values file.
